    How this was recorded. The reports are invented. The agent outputs are real: each step shows what a model returned on 16 Nov 2026, quoted or shortened, never rewritten. No model runs when you press Play.

    The two runs. "One agent alone" is the first verdict from the same recording, released without the review. It is not a separate run.

    The numbers. Model time is the measured duration of each call, added up. Cost is not shown yet.

    One thing the recording hides. An earlier pass of round 2, where the reviewer was given a shortened copy of the reports, held the status at AMBER. The same review step can land differently from one run to the next, which is why a person should still approve what leaves the building.
